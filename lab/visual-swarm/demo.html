What is actually running? A uniform-grid neighborhood search computes cohesion, separation and alignment signals on the CPU. Both execution paths then run the same Handwired FP32 circuit for agent steering and motion. The GPU renderer only draws results; it does not replace the physics computation. Host-side velocity limiting and boundary projection are identical for both paths.

Inspired by Craig Reynolds' boids and the open-source hughsk/boids ecosystem. Independent implementation, no training or copied source. Verified GPU support is device-dependent.
