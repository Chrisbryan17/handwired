What is actually running? Fast GPU-resident mode: WebGPU aggregates species-weighted neighborhoods into spatial grid cells, runs the genuine Handwired steering circuit in WGSL, integrates state and draws the flock directly on the GPU without per-frame readback. Its cell-aggregated approximation is not mathematically identical to the legacy pairwise model. The CPU pane shows a separately labeled 256-agent reference sample, not an identical-population speed comparison. Exact legacy mode: Both paths use the original CPU neighborhood algorithm and identical Handwired circuits, including readback; large populations will be slow. Frames/second is observable animation cadence, not isolated GPU kernel timing.

Inspired by Craig Reynolds' boids and the open-source hughsk/boids ecosystem. Independent implementation, no training or copied source. Verified GPU support is device-dependent.
