What's computed on the GPU? Each grid cell evaluates a fixed Handwired circuit for frontier detection, wall gating, visited-state exclusion and next-state propagation. Host code gathers neighboring frontier cells and reconstructs the final shortest path. This is neural circuit execution of BFS expansion, not a trained pathfinding model or a fully GPU-resident graph algorithm.
