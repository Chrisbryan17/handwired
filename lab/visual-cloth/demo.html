Scope disclosure. Full GPU mode computes spring forces, Handwired-generated Verlet integration, Jacobi constraints, collisions, pinning and persistent tear masks entirely on WebGPU. Hybrid mode preserves the original host-force/constraint path. The CPU uses sequential relaxation while the GPU uses parallel Jacobi, so they are not pixel-identical. Fast mode renders directly from resident GPU buffers and avoids per-frame GPU synchronization and readback. The original resident comparison and hybrid modes remain available.
