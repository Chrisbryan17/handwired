HOW TO READ THIS

CPU JavaScript is an independent handwritten numerical implementation. Handwired GPU and handwritten WGSL use identical surrounding fluid or cloth kernels; only the inline circuit implementation changes. The GPU columns measure GPU-resident simulation with a single final readback. Compilation and buffer initialization are excluded and shown separately. Measurements are not universal GPU speedup claims.

NUMERICAL LIMITATIONS

Fluid implementations use the same mathematical solver, with hardware-specific FP32 differences. Cloth's independent CPU baseline performs sequential constraint relaxation, while both GPU kernels use Jacobi relaxation; CPU/GPU cloth pose is therefore not bitwise comparable. Handwired and handwritten WGSL outputs are checked directly against each other after identical steps.
